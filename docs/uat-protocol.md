## 3. Ескертулер

Әр ескерту GitHub-та **UAT remark** шаблонымен ашылады. Топ пен басымдық **тапсырыс берушінің қасында, бірден** қойылады.

| # | Issue | Сценарий | Сипаттама | Топ | Басымдық | Шешім | Мерзімі |
|---|---|---|---|---|---|---|---|
| 1 | #__ | UAT-__ | | ☐ Ақау ☐ Нақтылау ☐ Өзгеріс сұранысы | P_ | | |
| 2 | #__ | UAT-__ | | ☐ Ақау ☐ Нақтылау ☐ Өзгеріс сұранысы | P_ | | |
| 3 | #__ | UAT-__ | | ☐ Ақау ☐ Нақтылау ☐ Өзгеріс сұранысы | P_ | | |

**«Шешім» бағаны:**
- ақау → «vX.Y.Z-де түзетіледі»;
- нақтылау → «критерий былай жаңартылды: …»;
- өзгеріс сұранысы → «+N күн, оның орнына X кейінге қалады» немесе «келесі кезеңге».

**Қорытынды:** ақау _N_ (P1: _N_, P2: _N_, P3–P4: _N_), нақтылау _N_, өзгеріс сұранысы _N_.

## 4. Қабылдау шешімі

☐ **Қабылданды** — барлық сценарий өтті, ашық ақаулар тек P3–P4

☐ **Ескертулермен қабылданды** — P1/P2 ақауы жоқ, түзету мерзімі: _ЖЖЖЖ-АА-КК_ дейін (3 жұмыс күнінен аспайды)

☐ **Қабылданбады** — P1/P2 ақауы немесе бұғаттаушы ескерту бар. Қайта UAT күні: _ЖЖЖЖ-АА-КК_
